# SlimeSweep 平滑音效版

三段情境：機械鍵盤、家具底部狹縫、座椅縫隙。各段 8 秒、1920×1080、48fps，附中文步驟字幕與立體聲音效。合併版以兩個 0.5 秒淡接轉場串連，共 23 秒。

相較前一版，每段原始渲染畫格由 36 張增加至 72 張，補渲染凝膠變形的中間畫格。播放時間由 6 秒放慢為 8 秒，並以動態補幀輸出 48fps。並未將增加的輸出幀全部宣稱為獨立 Blender 渲染。

音效為本次以程式合成的動作設計音效，包含推塊摩擦、卡榫、凝膠延伸、細碎灰塵吸附與回收聲，並非實體產品錄音。每段獨立 WAV 為 48kHz 立體聲，MP4 內已混入 AAC 音軌。

依使用者偏好，本專案後續影片預設加入與動作同步的音效。

`*_editable48.blend` 將動畫曲線重定時至 48fps／384 格，保留各段 8 秒的節奏；可在 Blender 4.3.2 開啟繼續編輯或重新渲染。獨立 WAV 可匯入剪輯軟體調整音量與混音。

凝膠為美術控制的連續隱式曲面，灰塵逐格貼合變形後的表面；推塊回拉時凝膠會收攏退回出口。此為機構概念動畫，未驗證真實材料、黏菌生長或產品回收性能。

工作流程：`render_smooth.py` 重用 `/workspace/output/slimesweep_v2` 的奇數畫格並補渲染偶數畫格；`denoise_guided.py` 使用 EXR 材質／法線通道輔助降噪；`make_sfx.py` 產生 WAV；`encode_smooth.py` 編碼三段 MP4 與帶轉場的合併版；`export_editable48.py` 匯出可編輯的 48fps 原檔。完整工作區仍保留上游 V2 場景與原始畫格。
